будем писать на примере `.gitlab-ci.yml`  

YAML-файл чувствителен к отступам - считай пробелы, *никаких tab!* 
сбитый отступ ломает весь файл!

###### Основные понятия конструкции
1. **Джоба (job)** - единица работы, список команд, у каждой джобы есть скрипт - те команды, которые я бы набирал в терминале
2. **Этап (stage)** - в него джобы группируются по смыслу, знакомому по анатомии паплайна: lint, test, build, deploy. Этапы идут строго по очереди, а джобы внутри этапа выполняются параллельно
3. **Пайплайн (pipeline)** - весь прогон целиком, все этапы о всеми добами для одного push

###### Пример:
```.yaml
stages:
  - test
  - build
   
run-tests:
  stage: test
  image: python:3.12
  script: 
    - pip install -r requirements.txt
    - pytest
       
build-image:
  stage: build
  image: docker:latest
  script: 
    - docker build -t myapp .
```
